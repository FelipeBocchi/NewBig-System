# 🚀 Como executar o sistema

## Antes de iniciar, verifique se o computador possui:

### - Java JDK instalado (versão 17 ou superior recomendada) 

### - WinRAR, 7-Zip ou similar para extrair arquivos .zip

### - IDE com suporte para JAVA

# 📥 Download do projeto

### - Baixe o arquivo `.zip` do sistema e extraia em uma pasta de sua preferência.

# 📦 Extraindo o projeto

### 1. Clique com o botão direito no arquivo `.zip`
### 2. Selecione:

```bash
Extrair aqui
```

# ▶️ Executando o sistema

### 1. Abra sua IDE de preferência que possua suporte a JAVA
### 2. Clique em:

```bash
Open Project
```

### 3. Selecione a pasta do projeto extraído
### 4. Aguarde o carregamento completo

# ▶️ Abrindo a classe principal

### Após abrir o projeto, siga este caminho:

```bash
src → main → java → com → newBig → system
```
### Depois, localize e execute o arquivo:

```bash
Main.java
```
# 📝 Observações

### - Não altere a estrutura das pastas
### - Mantenha todos os arquivos extraídos juntos
### - Não execute outros arquivos além do Main.java
### - Verifique se não possui dados no banco que possa gerar conflito
